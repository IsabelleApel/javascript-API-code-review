#Veckans Code Review-uppgift
Krav 1 Leta reda på valfritt API på nätet och lista ut hur du får tillgång till det. Skapa nu en ytterst liten webbplats med en enkel layout där du på något sätt använder dig av APIet. Kanske gör du endast ett GET-anrop för att hämta all data som renderas ut, eller vill du låta användarens handlingar avgöra vad som hämtas. Det är upp till dig själv.

Krav 2 Dela upp din kod i moduler. Till att börja med kan du skapa modulerna api.js (som sköter alla API-anrop), eventHandlers.js (som ställer in alla lyssnare) och domUtils.js (som gör saker med DOMen), men lägg gärna till fler om du vill det.

Detta behöver inte vara något avancerat du bygger, utan mer en övning för att utmana dig själv inför veckans Code Review, samt inför kommande examinationsuppgift (hint, hint).
